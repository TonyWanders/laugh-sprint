A program that writes one original funny line about everyday life to
`/output/entry.txt`, for the make.fun competition
[One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints exactly the line, with
no extra output. No network, no clock, no randomness. The line is 101
characters, inside the 1 to 200 gate.

## The line

```
My phone says I walked 10,000 steps today, mostly pacing while waiting for a text that just said 'k'.
```
